# 后端搬到腾讯云 · 部署手册（照着复制粘贴即可）

> 目标：把小程序后端从 Vercel 搬到腾讯云 124.222.33.233，用**已备案域名** `api.hgtcs.com`。
> 为什么要搬：**微信小程序 request 合法域名必须 ICP 备案**，`*.vercel.app` 未备案，真机和线上会被微信拦截，开发工具里能通是假象。
> 为什么选 hgtcs.com 不选 zmgen.cn：**hgtcs.com 已备案（`苏ICP备2026023229号`，备案主体=公司主体，微信校验双过关）**，且解析在腾讯云 DNSPod，加记录不用跳出控制台；zmgen.cn 解析在 Cloudflare 且主域挂了 Cloudflare Access 登录墙，还查不到备案记录，不碰。
> 全程不需要懂代码，只需要：腾讯云控制台的「登录」按钮（网页终端）+ 域名解析加一条记录。

---

## 第 0 步：域名解析（腾讯云控制台就能做，1 分钟）

hgtcs.com 的解析服务是 **DNSPod**（就在你截图那个域名列表的「解析」按钮进去）：

1. 腾讯云控制台 → **我的域名** → `hgtcs.com` 行点 **解析**
2. **添加记录**：
   - 主机记录：`api`
   - 记录类型：`A`
   - 记录值：`124.222.33.233`
   - TTL：默认 600 即可
3. 保存

等 2 分钟生效。验证（电脑 cmd 或网页终端都行）：

```
nslookup api.hgtcs.com
```

看到 `124.222.33.233` 就成了。

---

## 第 1 步：进服务器

腾讯云控制台 → 云服务器 → 实例 → 找到 124.222.33.233 → 点「**登录**」→ 用网页终端登录（不用装任何东西）。

登录后先确认是不是 root，不是就先切：

```
sudo -i
```

---

## 第 2 步：把代码弄到服务器上（二选一）

### 方式 A：GitHub 公开仓库（最简单）

```
cd /opt
git clone https://github.com/kszdf/risk-detector.git
cd risk-detector
```

### 方式 B：仓库是私有的

去 GitHub → 右上角头像 → **Settings** → **Developer settings** → **Personal access tokens** → 生成一个勾选 `repo` 的令牌，然后：

```
cd /opt
git clone https://<你的令牌>@github.com/kszdf/risk-detector.git
cd risk-detector
```

> 如果服务器上装不了 git 或网络不通 GitHub，改方式 C：**在我本机把代码打包成 tar，你在腾讯云控制台用「上传文件」传到 `/opt/`**，再 `tar -zxvf risk-detector.tar.gz`。

---

## 第 3 步：填密钥（7 个变量）

```
cd /opt/risk-detector/deploy
cp env.example .env
vi .env
```

按 `i` 进入编辑，填成这样（值问我要，或沿用 Vercel 里那 7 个）：

```
FEISHU_APP_ID=xxx
FEISHU_APP_SECRET=xxx
FEISHU_BASE_TOKEN=xxx
FEISHU_TABLE_ID=xxx
QCC_APP_KEY=xxx
QCC_SECRET_KEY=xxx
ADMIN_TOKEN=HuiGenTang2026#Ks
```

按 `Esc` → 输入 `:wq` → 回车保存。

---

## 第 4 步：装 Docker（服务器已有就跳过）

```
docker -v
```

能显示版本号就跳过本步。否则：

```
curl -fsSL https://get.docker.com | bash
systemctl enable docker && systemctl start docker
```

---

## 第 5 步：构建并启动（约 3-5 分钟）

```
cd /opt/risk-detector
docker compose -f deploy/docker-compose.yml up -d --build
```

跑完看一眼是不是起来了：

```
docker ps | grep risk-detector-api
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:3100/
```

返回 `200` 或 `307` 都算成功（404 也算通了，说明服务活着）。

---

## 第 6 步：装 nginx + 申请证书

已有 nginx 就只做证书部分。

```
apt-get update -y && apt-get install -y nginx certbot python3-certbot-nginx
# CentOS 用：yum install -y nginx certbot python3-certbot-nginx
```

放配置文件（把我给你的 `nginx-api.hgtcs.com.conf` 内容贴进去）：

```
vi /etc/nginx/conf.d/api.hgtcs.com.conf
```

⚠️ 第一次先只留 `listen 80` 那一段（443 段先删掉或注释），因为证书还没签发。然后：

```
mkdir -p /var/www/html
nginx -t && systemctl reload nginx
certbot certonly --webroot -w /var/www/html -d api.hgtcs.com
```

证书签发成功后，再把 443 段补回去：

```
vi /etc/nginx/conf.d/api.hgtcs.com.conf
nginx -t && systemctl reload nginx
```

证书 90 天过期，certbot 会自动续，不用管。

---

## 第 7 步：验证（手机上做这个最准）

服务器里先自测：

```
curl -s -o /dev/null -w "%{http_code}\n" https://api.hgtcs.com/
```

然后**用手机流量**（关掉 WiFi）打开 `https://api.hgtcs.com/`，能出页面（哪怕 404）就说明国内通了。

---

## 第 8 步：小程序后台配合法域名（最后一步）

微信公众平台 → 开发与服务 → 开发管理 → 开发设置 → **服务器域名** → 修改 → request 合法域名填：

```
https://api.hgtcs.com
```

保存后等 10 分钟生效。同时**小程序前端里的接口地址要从 `xxx.vercel.app` 改成 `https://api.hgtcs.com`**。

---

## 出问题看这里

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `certbot` 报 timeout / 验证失败 | 解析还没生效 | 等 5 分钟再试；`nslookup api.hgtcs.com` 确认指向 124.222.33.233 |
| `docker compose` 命令不存在 | Docker 版本太老 | 用 `docker-compose`（中间是横杠） |
| 容器起不来 | 环境变量没填全 | `docker logs risk-detector-api` 看报错 |
| 手机打不开 | 服务器防火墙/安全组没放 443 | 腾讯云控制台 → 安全组 → 放行 80、443 |

---

## 一句话总结

搬过去的唯一原因就是**域名要备案**——小程序不认没备案的接口地址。搬完之后，Vercel 那边可以留着当备用（同样的代码两边都能跑），哪天腾讯云出问题还能切回去做临时顶替。

# 后端搬到腾讯云 · 部署手册（照着复制粘贴即可）

> 目标：把「税检康」小程序后端（risk-detector）搬到腾讯云服务器，用**已备案域名** `taxcheck.hgtcs.com`。
> 为什么要搬：**微信小程序 request 合法域名必须 ICP 备案**，`*.vercel.app` 未备案，真机和线上会被微信拦截，开发工具里能通是假象。
> 为什么选 hgtcs.com 不选 zmgen.cn：**hgtcs.com 已备案（`苏ICP备2026023229号`，备案主体=公司主体，微信校验双过关）**，且解析在腾讯云 DNSPod，加记录不用跳出控制台；zmgen.cn 解析在 Cloudflare 且主域挂了 Cloudflare Access 登录墙，还查不到备案记录，不碰。
> 全程不需要懂代码，只需要：腾讯云控制台的「登录」按钮（网页终端）+ 域名解析加一条记录。

---

## ⚠️ 先读这一段：服务器现状（2026-10-04 更新）

**旧服务器 `124.222.33.233` 已作废**——本机实测 `ping` 100% 丢包，且域名 `tax.hgtcs.com` 仍指向它（僵尸记录，需一并清理）。

因此本手册适用于**两种情况**，请按你的实际情况选：

- **情况一（临时）：先把域名指向 Vercel，不搬服务器。**
  后端继续跑在 Vercel（`risk-detector.vercel.app`），只在 DNSPod 把 `taxcheck` 记录 CNAME 到 Vercel。
  优点：5 分钟搞定、不用买机器。缺点：**备案合规性存疑**（CNAME 到境外平台的域名，微信校验未必认），且仍受境外网络波动影响。
- **情况二（推荐）：按本手册把后端搬到一台国内腾讯云服务器。**
  备案最稳、访问最快、彻底摆脱境外依赖。需要一台新服务器（旧的那台已废）。

> 本文档按**情况二**写。若先按情况一做临时验证，只需做「第 0 步」的变体（见文末附录）。

---

## 第 0 步：域名解析（腾讯云控制台就能做，1 分钟）

hgtcs.com 的解析服务是 **DNSPod**（就在你截图那个域名列表的「解析」按钮进去）：

1. 腾讯云控制台 → **我的域名** → `hgtcs.com` 行点 **解析**
2. 先**删掉僵尸记录**：找到主机记录为 `api` 和 `tax` 的旧记录，删除
   （`api` 原指向 Vercel，`tax` 原指向已作废的 124.222.33.233，都不要再留）
3. **添加新记录**：
   - 主机记录：`taxcheck`
   - 记录类型：`A`
   - 记录值：`<新服务器的公网 IP>`
   - TTL：默认 600 即可
4. 保存

等 2 分钟生效。验证（电脑 cmd 或网页终端都行）：

```
nslookup taxcheck.hgtcs.com
```

看到新服务器的公网 IP 就成了。

---

## 第 1 步：进服务器

腾讯云控制台 → 云服务器 → 实例 → 找到**新服务器** → 点「**登录**」→ 用网页终端登录（不用装任何东西）。

登录后先确认是不是 root，不是就先切：

```
sudo -i
```

---

## 第 2 步：把代码弄到服务器上（二选一）

### 方式 A：GitHub 公开仓库（最简单）

```
cd /opt
git clone https://github.com/kszdf/risk-detector.git
cd risk-detector
```

### 方式 B：仓库是私有的

去 GitHub → 右上角头像 → **Settings** → **Developer settings** → **Personal access tokens** → 生成一个勾选 `repo` 的令牌，然后：

```
cd /opt
git clone https://<你的令牌>@github.com/kszdf/risk-detector.git
cd risk-detector
```

> 如果服务器上装不了 git 或网络不通 GitHub，改方式 C：**在我本机把代码打包成 tar，你在腾讯云控制台用「上传文件」传到 `/opt/`**，再 `tar -zxvf risk-detector.tar.gz`。

---

## 第 3 步：填密钥（7 个变量）

```
cd /opt/risk-detector/deploy
cp env.example .env
vi .env
```

按 `i` 进入编辑，填成这样（值问我要，或沿用 Vercel 里那 7 个）：

```
FEISHU_APP_ID=xxx
FEISHU_APP_SECRET=xxx
FEISHU_BASE_TOKEN=xxx
FEISHU_TABLE_ID=xxx
QCC_APP_KEY=xxx
QCC_SECRET_KEY=xxx
ADMIN_TOKEN=HuiGenTang2026#Ks
```

按 `Esc` → 输入 `:wq` → 回车保存。

---

## 第 4 步：装 Docker（服务器已有就跳过）

```
docker -v
```

能显示版本号就跳过本步。否则：

```
curl -fsSL https://get.docker.com | bash
systemctl enable docker && systemctl start docker
```

---

## 第 5 步：构建并启动（约 3-5 分钟）

```
cd /opt/risk-detector
docker compose -f deploy/docker-compose.yml up -d --build
```

跑完看一眼是不是起来了：

```
docker ps | grep risk-detector-api
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:3100/
```

返回 `200` 或 `307` 都算成功（404 也算通了，说明服务活着）。

---

## 第 6 步：装 nginx + 申请证书

已有 nginx 就只做证书部分。

```
apt-get update -y && apt-get install -y nginx certbot python3-certbot-nginx
# CentOS 用：yum install -y nginx certbot python3-certbot-nginx
```

放配置文件（把我给你的 `nginx-taxcheck.hgtcs.com.conf` 内容贴进去）：

```
vi /etc/nginx/conf.d/taxcheck.hgtcs.com.conf
```

⚠️ 第一次先只留 `listen 80` 那一段（443 段先删掉或注释），因为证书还没签发。然后：

```
mkdir -p /var/www/html
nginx -t && systemctl reload nginx
certbot certonly --webroot -w /var/www/html -d taxcheck.hgtcs.com
```

证书签发成功后，再把 443 段补回去：

```
vi /etc/nginx/conf.d/taxcheck.hgtcs.com.conf
nginx -t && systemctl reload nginx
```

证书 90 天过期，certbot 会自动续，不用管。

---

## 第 7 步：验证（手机上做这个最准）

服务器里先自测：

```
curl -s -o /dev/null -w "%{http_code}\n" https://taxcheck.hgtcs.com/
```

然后**用手机流量**（关掉 WiFi）打开 `https://taxcheck.hgtcs.com/`，能出页面（哪怕 404）就说明国内通了。

---

## 第 8 步：小程序后台配合法域名（最后一步）

微信公众平台 → 开发与服务 → 开发管理 → 开发设置 → **服务器域名** → 修改 → request 合法域名填：

```
https://taxcheck.hgtcs.com
```

保存后等 10 分钟生效。同时**小程序前端里的接口地址要从 `xxx.vercel.app` 改成 `https://taxcheck.hgtcs.com`**。

> 小程序前端工程不在本仓库，需另在小程序开发者工具里全局搜索替换域名，改完重新上传审核。

## 出问题看这里

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `certbot` 报 timeout / 验证失败 | 解析还没生效 | 等 5 分钟再试；`nslookup taxcheck.hgtcs.com` 确认指向新服务器 IP |
| `docker compose` 命令不存在 | Docker 版本太老 | 用 `docker-compose`（中间是横杠） |
| 容器起不来 | 环境变量没填全 | `docker logs risk-detector-api` 看报错 |
| 手机打不开 | 服务器防火墙/安全组没放 443 | 腾讯云控制台 → 安全组 → 放行 80、443 |

## 附录：情况一（不搬服务器，临时指向 Vercel）

如果暂时不买服务器，只想先把域名换掉、马上验证：

1. 在 DNSPod 删掉 `api` 和 `tax` 的旧记录
2. 添加记录：
   - 主机记录：`taxcheck`
   - 记录类型：`CNAME`
   - 记录值：`risk-detector.vercel.app`
3. 去 Vercel 项目 → Settings → Domains → 添加 `taxcheck.hgtcs.com`
4. 验证：`nslookup taxcheck.hgtcs.com` 应看到 Vercel 的 IP

⚠️ 此方式**备案合规性存疑**（微信校验未必认 CNAME 到境外平台），只建议临时过渡，正式上线仍须按情况二搬到国内服务器。

---

## 一句话总结

搬过去的唯一原因就是**域名要备案**——小程序不认没备案的接口地址。搬完之后，Vercel 那边可以留着当备用（同样的代码两边都能跑），哪天腾讯云出问题还能切回去做临时顶替。
